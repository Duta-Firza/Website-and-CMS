Bab 1 Pendahuluan

1.1 Tujuan buku ini

Buku ini adalah panduan praktis untuk mengelola website PT Duta Firza melalui dashboard admin (CMS). Setelah membaca buku ini, admin diharapkan mampu:

  • Masuk ke dashboard admin dan memahami tata letaknya.
  • Mengatur konten setiap halaman — teks, gambar, dokumen — dalam dua bahasa (Indonesia & Inggris).
  • Memahami di mana dan bagaimana setiap konten muncul di website publik.
  • Membaca data pengunjung serta menindaklanjuti pesan masuk (inquiry, lamaran kerja, dan lead unduhan laporan).
  • Mengelola akun pengguna admin beserta hak aksesnya.

1.2 Untuk siapa buku ini

Buku ini ditujukan untuk admin non-teknis yang bertugas memelihara konten website sehari-hari. Bagian teknis (Bab 7) ditujukan untuk pengelola sistem/IT dan boleh dilewati oleh editor konten.

1.3 Ikhtisar website & CMS

Website PT Duta Firza terdiri dari dua sisi:

  • Sisi Publik — halaman yang dilihat pengunjung (beranda, profil, solusi/layanan, hubungan investor, kontak, karir). Alamatnya diawali /id/… (Indonesia) atau /en/… (Inggris).
  • Sisi Admin (CMS) — tempat mengelola semua konten di atas. Alamatnya diawali /id/admin. Hanya bisa diakses setelah login.

Setiap perubahan yang Anda simpan di sisi admin akan langsung tampil di sisi publik (kecuali status halaman diatur tersembunyi/segera hadir — lihat bagian 3.6).

Info Teknis Singkat

Website dibangun dengan Next.js + MongoDB, mendukung dua bahasa, tema terang/gelap, editor teks kaya, unggah gambar & PDF, peta lokasi, dan analitik pengunjung (Umami). Anda tidak perlu memahami teknologi ini untuk memakai CMS.

Bab 2 Memulai

2.1 Masuk (login) & keluar (logout)

  1. Buka peramban (Chrome/Edge/Safari) dan kunjungi /id/admin/login (mis. https://dutafirza.com/id/admin/login).
  2. Masukkan Email dan Kata sandi akun admin Anda.
  3. Klik tombol Masuk. Bila berhasil, Anda diarahkan ke /id/admin (Dasbor).
Bila gagal masuk

Pesan "Email atau kata sandi salah" berarti kredensial keliru. Jika akun Anda dinonaktifkan atau sesi berakhir, sistem akan mengembalikan Anda ke halaman login. Hubungi Super Admin bila perlu reset kata sandi (lihat 6.3).

Keluar (logout): klik nama/avatar Anda di pojok bawah sidebar, lalu pilih Keluar.

2.2 Orientasi dashboard & sidebar

Setelah masuk, layar terbagi menjadi dua: sidebar menu di kiri dan area kerja di kanan. Menu dikelompokkan menjadi empat bagian:

BagianIsi menuFungsi
AnalitikDasbor, Analitik PengunjungRingkasan & data trafik.
KontenBeranda, Tentang Kami, Solusi, Hubungan Investor, ConnectSemua konten yang tampil ke publik.
InboxInquiry, Lamaran Kerja, Download LaporanPesan & lead yang masuk.
SistemPenggunaKelola akun admin (khusus Super Admin).

Angka merah kecil (badge) pada menu Inquiry dan Lamaran Kerja menunjukkan jumlah pesan yang belum dibaca dan diperbarui otomatis.

Catatan RBAC

Menu yang tampil bergantung pada peran & hak akses akun Anda. Editor mungkin hanya melihat sebagian menu. Menu Pengguna hanya muncul untuk Super Admin. Lihat Bab 6.

Halaman Dasbor menampilkan kartu ringkasan tiap kelompok konten dan inbox — berguna sebagai titik awal navigasi. Sidebar bisa diperlebar/diringkas lewat tombol Perluas/Ringkas sidebar.

2.3 Ganti bahasa antarmuka & tema

Di pojok bawah sidebar (menu akun) tersedia:

  • Pengalih bahasa — mengubah bahasa tampilan CMS antara Indonesia & Inggris. (Ini berbeda dari mengisi konten dua bahasa — lihat 3.1.)
  • Pengalih tema — Terang / Gelap / Ikuti sistem.
  • Ganti kata sandi — untuk mengubah kata sandi akun Anda sendiri (lihat 6.3).

Bab 3 Konsep Dasar (dipakai di semua halaman)

Sebagian besar halaman CMS memakai elemen antarmuka yang sama. Pahami sekali di sini, lalu Anda bisa mengelola halaman mana pun di Bab 4–6.

3.1 Konten dua bahasa (ID/EN)

Hampir semua field teks (Judul, Deskripsi, Ringkasan, dll.) memiliki dua versi: Indonesia dan Inggris. Field seperti ini punya penanda/tab bahasa ID dan EN. Isi keduanya agar konten tampil benar di kedua versi bahasa website.

Penting

Jika versi EN dibiarkan kosong, pengunjung berbahasa Inggris bisa melihat bagian kosong (kecuali dinyatakan "boleh kosong → memakai teks Indonesia", seperti pada sel tabel pemegang saham). Biasakan mengisi kedua bahasa.

3.2 Editor teks kaya (rich text)

Untuk isi panjang (paragraf, isi artikel, deskripsi pekerjaan) tersedia editor teks kaya dengan toolbar: tebal, miring, judul, daftar, tautan, dan sisip gambar. Gunakan toolbar ini untuk memformat; hindari menempel format mentah dari Word.

3.3 Unggah & crop gambar/video

Untuk gambar/logo/foto: klik area unggah atau seret berkas (drag & drop). Setelah memilih gambar, muncul dialog Crop gambar:

  1. Atur Zoom dan geser gambar untuk menentukan area yang tampil.
  2. Klik Terapkan crop untuk memakai hasil potongan, atau Unggah gambar utuh untuk memakai gambar apa adanya.
  3. Sistem mengompres gambar otomatis dan menampilkan penghematan ukuran (mis. "2 MB → 400 KB").
Ukuran gambar yang disarankan

Setiap field gambar mencantumkan rekomendasi ukuran & rasio (mis. hero 1920×1080/16:9, foto pimpinan potret 4:5, logo mitra PNG transparan). Ikuti anjuran ini agar hasil tampil rapi. Detail per konten ada di Bab 4.

Video (khusus halaman About): unggah MP4; sistem mengompres ke 1080p. Ada opsi putar otomatis tanpa suara.

3.4 Pemilih ikon & pemilih titik peta

  • Pemilih ikon — beberapa kartu (Statistik & Solusi di beranda) memakai ikon. Klik untuk memilih dari daftar ikon yang tersedia.
  • Pemilih titik peta — pada Jangkauan (peta di beranda), klik di peta atau geser pin untuk menentukan koordinat lokasi.

3.5 Mengubah urutan (drag & drop)

Daftar item (statistik, mitra, produk, milestone, dll.) bisa diurutkan dengan menyeret. Tarik pegangan (⋮⋮) sebuah item ke posisi baru.

Syarat mengurutkan

Fitur seret-urut hanya aktif saat daftar dalam urutan manual. Bila Anda sedang mencari/memfilter/mengurutkan berdasarkan nama, hapus dulu pencarian & filter agar bisa menyeret.

3.6 Status halaman & mode section

Banyak halaman publik punya Status yang menentukan apakah halaman tampil:

StatusPerilaku di publik
TayangHalaman dapat diakses publik secara normal.
Segera HadirPengunjung melihat halaman "Segera Hadir".
DisembunyikanHalaman menampilkan 404 dan tidak muncul di navigasi.

Selain itu, banyak section (Judul & Body halaman) punya mode:

  • Section aktif (on/off) — nyalakan/matikan tampilnya section.
  • Default — memakai teks bawaan sistem.
  • Custom — memakai teks yang Anda tulis sendiri.

3.7 Menyimpan & melihat pratinjau

Saat Anda mengubah sesuatu, muncul bar simpan di bawah layar. Klik Simpan untuk menyimpan; status berubah menjadi "Tersimpan". Banyak halaman juga punya tombol Lihat halaman publik untuk membuka hasilnya di tab baru.

Jangan lupa Simpan

Perubahan hanya berlaku setelah Simpan ditekan. Meninggalkan halaman tanpa menyimpan akan membatalkan perubahan.

3.8 Mencari, memfilter & mengurutkan daftar

Halaman berbentuk daftar (produk, proyek, artikel, inquiry, pengguna) punya toolbar: kotak Cari, Filter (status/kategori), Urutkan, dan pengalih tampilan kartu/tabel. Bawah daftar ada penomoran halaman (pagination).

Bab 5 Membaca Data & Menindaklanjuti Inbox

Bab ini menjelaskan cara membaca angka & menindaklanjuti pesan yang masuk dari website.

5.1 Dasbor (ringkasan)

Lokasi: /id/admin. Dasbor menampilkan kartu ringkasan setiap kelompok konten dan inbox, plus tanggal pembaruan. Gunakan sebagai titik awal untuk melompat ke area yang perlu dikelola. Isi kartu menyesuaikan hak akses akun Anda.

5.2 Analitik Pengunjung (Umami)

Lokasi: /id/admin/visitor-analytics. Menampilkan trafik situs publik yang diukur oleh Umami, tertanam langsung di dalam dashboard. Tombol Buka di Umami membuka dasbor Umami penuh di tab baru.

Yang biasa dibaca: jumlah pengunjung & tampilan halaman, halaman terpopuler, sumber rujukan (referrer), perangkat, dan negara/kota. Gunakan rentang tanggal untuk membandingkan periode.

Bila tampil "Belum dikonfigurasi"

Berarti kredensial Umami belum diisi. Ini tugas teknis — lihat 7.1.

5.3 Inbox Inquiry

Lokasi: /id/admin/inquiries. Berisi kiriman dari form Trading, Manufaktur, EPC, Teknologi, dan Kontak. Menu ini menampilkan badge jumlah belum dibaca.

Tab penyaring

Semua · Belum dibaca · Baru · Dibaca · Diproses · Selesai · Diarsipkan. Ada pula kotak cari (perusahaan, nama, email).

Menindaklanjuti sebuah inquiry

  1. Klik sebuah baris untuk membuka detail (isi pesan + info pengirim & sumber form).
  2. Perbarui status sesuai progres: Baru → Diproses → Selesai (atau Diarsipkan).
  3. Tandai dibaca / belum dibaca sesuai kebutuhan.
  4. Klik Balas via email untuk membalas lewat aplikasi email Anda.
Baca ≠ Status

"Belum dibaca/Dibaca" hanya penanda apakah Anda sudah membuka pesan. "Status" (Baru/Diproses/Selesai/Diarsipkan) adalah alur tindak lanjut yang terpisah.

5.4 Lamaran Kerja

Lokasi: /id/admin/applications. Berisi lamaran dari form karir (metode "Form di website ini"), lengkap dengan CV. Alur status (pipeline rekrutmen):

Baru → Direview → Shortlist → Ditolak / Diterima

Buka sebuah lamaran untuk melihat detail & klik Unduh CV untuk mengambil berkas pelamar.

5.5 Download Laporan (lead)

Lokasi: /id/admin/report-downloads. Menangkap lead ketika pengunjung melihat atau mengunduh PDF laporan investor. Terdapat dua bagian:

  • Lihat lead tertangkap — daftar lead (nama, perusahaan, email, laporan) dengan penanda aksi Lihat atau Download. Bisa difilter per jenis laporan (Tahunan/Keuangan) dan dicari.
  • Pengaturan form — aktif/nonaktifkan "gate": mewajibkan pengunjung mengisi data sebelum melihat/mengunduh. Empat field inti selalu dikumpulkan; field lain bisa ditambah/dihapus.
Notifikasi

Inquiry & lamaran baru dapat memicu notifikasi email otomatis (via layanan Resend), dan badge "belum dibaca" di sidebar diperbarui secara langsung tanpa perlu me-refresh.

Bab 6 Manajemen Pengguna & Hak Akses (RBAC)

Lokasi: /id/admin/users. Hanya Super Admin yang dapat membuka menu ini.

6.1 Peran: Super Admin, Editor, Viewer

PeranHak
Super AdminAkses penuh ke semua section, plus mengelola pengguna.
EditorHanya bisa mengubah section yang dicentang pada "Akses section". Dasbor selalu tersedia.
ViewerHanya baca (tidak bisa mengubah apa pun).
Akses section (scope)

Untuk Editor, centang section mana yang boleh dibuka & diubah (mis. hanya "Newsroom" & "Siaran Pers"). Ini membuat pembagian tugas rapi — mis. tim humas hanya mengurus publikasi, tim HR hanya mengurus karir & lamaran.

6.2 Menambah & menyunting pengguna

  1. Klik Tambah pengguna, isi nama, email, kata sandi, dan pilih peran.
  2. Jika peran Editor, centang section yang boleh diaksesnya.
  3. Klik Simpan.

Menonaktifkan (hapus): akun dinonaktifkan & disembunyikan, dan emailnya bebas dipakai lagi. Perubahan peran/nonaktif langsung berlaku pada permintaan berikutnya pengguna tersebut.

Pengaman

Anda tidak bisa menghapus, menonaktifkan, atau menurunkan peran akun sendiri. Super Admin aktif terakhir tidak boleh diturunkan — angkat Super Admin lain lebih dulu.

6.3 Reset & ganti kata sandi

  • Reset kata sandi (untuk orang lain) — Super Admin menetapkan kata sandi baru untuk pengguna. Pengguna tidak diberi notifikasi otomatis, jadi sampaikan langsung.
  • Ganti kata sandi (akun sendiri) — lewat menu akun di sidebar; masukkan kata sandi saat ini + kata sandi baru.
Aturan kata sandi

Minimal 12 karakter. Konfirmasi harus cocok.

Bab 7 Lampiran Teknis & Operasional

Untuk pengelola sistem / IT

Bagian ini bersifat teknis dan umumnya tidak diperlukan editor konten sehari-hari. Perubahan di sini biasanya butuh akses server/hosting.

7.1 Konfigurasi Analitik (Umami)

Agar halaman Analitik Pengunjung menampilkan data, isi variabel lingkungan berikut lalu deploy ulang:

NEXT_PUBLIC_UMAMI_WEBSITE_ID="…"
NEXT_PUBLIC_UMAMI_SHARE_URL="…"

GBR-7.1 (opsional) — layar "Belum dikonfigurasi" beserta langkah setup dapat difoto sebagai referensi.

7.2 Variabel lingkungan (.env) & deploy

  • Seluruh variabel didokumentasikan di berkas .env.example (MongoDB URI, kunci Resend, kredensial GCS, Umami, dll.). Salin ke .env.local untuk lokal.
  • Aplikasi memvalidasi variabel saat boot — bila ada yang kurang/salah, aplikasi gagal start dengan pesan jelas.
  • Build: pnpm build. Hosting: GCP Cloud Run (lihat README repo).

7.3 Cadangan data & pemulihan

  • Semua konten & pesan tersimpan di MongoDB; berkas (gambar/PDF/CV) di Google Cloud Storage.
  • Jadwalkan cadangan berkala database (mis. mongodump) dan pastikan bucket GCS memiliki kebijakan retensi. Simpan salinan kredensial secara aman.

Cara menempel gambar (tanpa edit HTML)

Seret & lepaskan berkas gambar langsung ke kotak placeholder tempat gambar itu akan tampil, atau klik kotaknya untuk memilih file. Gambar otomatis dikompres (maks 1600px, JPEG) dan tersimpan di peramban Anda. Gunakan tombol Ganti / Hapus pada gambar untuk mengubahnya.

Pekerjaan tersimpan otomatis di peramban. Klik Ekspor (panel kanan bawah) untuk membuat cadangan .json, dan Impor untuk memuatnya kembali di komputer lain. Setelah semua gambar terpasang: Cetak (Ctrl/Cmd+P) → Save as PDF — semua tombol bantu otomatis tersembunyi di hasil PDF.

Menyimpan gambar sebagai file (untuk git): di panel kanan bawah, klik 💾 Simpan ke folder gambar/ (Chrome/Edge) lalu pilih folder docs/manual — semua gambar ditulis sebagai gambar/GBR-x.y.jpg, siap di-commit. Peramban lain: pakai Unduh ZIP, ekstrak isinya ke dalam docs/manual/ (akan membuat folder gambar/). Setelah file ada di folder, HTML akan otomatis memuat gambar dari sana saat dibuka — jadi hasil commit tampil utuh bagi siapa pun.
